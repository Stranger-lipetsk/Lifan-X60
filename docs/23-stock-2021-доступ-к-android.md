# 23. Доступ к Android на stock 2021

## Что проверено в файле

Исходник — `x60_2021.7z` из релиза `stock`. SHA-256 архива:

```text
75e7d6cd900fac971b55fec9f59913153bf7a1096bd761f7229c9a1d6d57b540
```

Архив содержит `system.img`, `boot.img`, `sd_boot.img`, `u-boot.bin`,
`MCU_FW.hex` и `backup/config.ini`. В `system.img` указана Android 4.4.2
(API 19), процессор armeabi-v7a. Родная оболочка —
`/priv-app/EL830LF01_Home.apk`, пакет `tw.com.elead.el830.home`. В образе
есть `/app/PackageInstaller.apk` и `/priv-app/ElSettings.apk`.

Файл `/priv-app/Launcher2` является APK пакета `com.android.launcher`, но
не имеет расширения `.apk`. Это не доказывает, что пакет установлен и
доступен; нужна проверка на устройстве. В стоке уже есть приложение
MirrorLink с пакетом `com.fpt.mirrorlink.android`: заменять его нашей панелью
без отдельной проверки не следует. Отчёт автоматической проверки:
`reports/stock-2021-inspection.txt`.

На 03.11.2026 пользователь сообщил, что ему доступен только USB для флешки;
отдельный порт для ADB не подтверждён. Нельзя считать, что mini-USB есть у
пользователя: фото разъёмов не предоставлено. USB-хосты ноутбука и магнитолы
нельзя соединять обычным кабелем USB-A—USB-A.

## Сначала восстановить сток

Пользователь ранее ставил эту прошивку на свою магнитолу, но на момент начала
проверки устройство застряло на логотипе после `lite-stage1`. Прошейте
**неизменённый** архив stock привычным способом; до Start отметьте Android,
снимите MCU и Clear Navi. При обновлении данные Android во внутренней памяти
могут стереться. Не отключайте питание и не извлекайте носитель во время
прошивки. Сначала дождитесь рабочего экрана и убедитесь, что сток работает.

## Проверка ADB без изменения прошивки

1. На Windows скачайте и распакуйте официальные Android SDK Platform Tools:
   <https://developer.android.com/tools/releases/platform-tools>.
2. Подключите ноутбук к **устройственному USB/OTG-порту** магнитолы кабелем
   с линиями данных. Обычный USB-хост для флешек для этого может не подойти.
   Физический тип разъёма и доступность ADB на этой конкретной сборке пока
   не подтверждены — проверьте на устройстве, не подключайте два USB-хоста.
3. В папке platform-tools откройте PowerShell и выполните:

   ```powershell
   .\adb.exe devices
   ```

4. `device` означает, что ADB подключён; `unauthorized` — требуется разрешить
   отладку в появившемся на магнитоле запросе; пустой список или `offline`
   означает, что связь ещё не установлена. Пришлите полный текст результата.

Если ADB работает, можно попробовать открыть настройки Android:

```powershell
.\adb.exe shell am start -a android.settings.SETTINGS
```

Это **проба**, а не подтверждённый выход на рабочий стол: в заводской сборке
нужное действие может отсутствовать или открывать фирменные настройки.
Пришлите ответ команды и фото экрана. Пока не меняйте лаунчер по умолчанию.

С разрешённым ADB APK можно ставить напрямую с ноутбука, без выхода в меню:

```powershell
.\adb.exe install "C:\путь\к\приложению.apk"
```

Поддержка конкретного APK и наличие нужной подписи для обновления уже
установленного приложения проверяются отдельно. Для самостоятельной установки
с экрана и входа через MirrorLink сначала исследуем эту прошивку и проверим
доступные способы запуска; готового проверенного решения пока нет.
