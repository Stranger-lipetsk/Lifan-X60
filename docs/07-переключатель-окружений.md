# Доступ к Android, Wi-Fi и файлам: «Переключатель окружений»

## Проблема

В штатной оболочке Elead Home нет списка приложений, выхода в настройки Android,
к Wi-Fi и файловому менеджеру. При этом **всё это в системе есть** — проверено по образу:

| Что нужно | Пакет в системе | Состояние |
|---|---|---|
| Стандартный лаунчер Android | **`com.android.launcher`** (Launcher2, 11.7 МБ) | есть, объявляет `CATEGORY_HOME` |
| Настройки Android + Wi-Fi | **`com.android.settings`** (это `ElSettings.apk`) | есть, обрабатывает все `android.settings.*` |
| Файловый менеджер | `com.android.documentsui` (DocumentsUI) | есть |
| Установка приложений | `PackageInstaller`, `DownloadProvider` | есть |
| Оболочка магнитолы | `tw.com.elead.el830.home` (EL830LF01_Home) | есть |

`ElSettings.apk` — это **не урезанные настройки**, а полный `com.android.settings`.
Он объявляет обработчиками все нужные экраны:

```
android.settings.SETTINGS                      android.settings.WIFI_SETTINGS
android.settings.WIRELESS_SETTINGS             android.settings.BLUETOOTH_SETTINGS
android.settings.MANAGE_APPLICATIONS_SETTINGS  android.settings.APPLICATION_SETTINGS
android.settings.INTERNAL_STORAGE_SETTINGS     android.settings.DISPLAY_SETTINGS
android.settings.APPLICATION_DEVELOPMENT_SETTINGS  … и ещё 35 действий
```

То есть **ничего доустанавливать не нужно** — нужна только точка входа.

## Почему нельзя просто «добавить ярлык»

Я разобрал `EL830LF01_Home.apk`. Внутри — **жёстко прописанный список пакетов**,
которые оболочка вообще знает:

```
tw.com.elead.el830.avin, .ccd, .dtv, .dvd, .dvr, .hdmi, .ipod, .mediaplayer,
.radio, .setup, .update, .wifi, .ezlife, .eztalk, .ewhere …
com.android.launcher, com.android.browser, com.android.music, com.android.camera2,
com.navitel, com.fpt.mirrorlink.android, com.nuro.r1.main …
```

Своего приложения там нет, и оболочка не сканирует установленные программы
(в коде нет `queryIntentActivities` для построения списка). Добавить ярлык
правкой APK нельзя — он подписан, а переподпись сломает подпись системы.

**Вывод:** нужна точка входа, которая не зависит от оболочки.

## Решение: приложение-лаунчер `ru.lifan.switcher`

Собрано специально под это ГУ: `switcher/` в репозитории, APK 16.9 КБ,
`minSdk 19`, подпись v1 (обязательна для Android 4.4).

Приложение объявляет себя **домашним экраном** (`CATEGORY_HOME`). Если назначить
его лаунчером по умолчанию — нажатие кнопки «Домой» и каждая загрузка ГУ
приводят на панель переключения.

### Что на панели

| Кнопка | Что делает |
|---|---|
| **Магнитола (штатная оболочка)** | `tw.com.elead.el830.home` |
| **Стандартный Android (рабочий стол)** | `com.android.launcher` — обычный Android-лаунчер со списком всех приложений |
| **Настройки Android** | `android.settings.SETTINGS` |
| **Настройки Wi-Fi** | `android.settings.WIFI_SETTINGS` |
| **Приложения: установка и удаление** | `android.settings.MANAGE_APPLICATIONS_SETTINGS` |
| **Файловый менеджер** | DocumentsUI |
| **Память и USB-накопители** | `INTERNAL_STORAGE_SETTINGS` |
| **Для разработчиков (ADB)** | `APPLICATION_DEVELOPMENT_SETTINGS` |
| **Автовозврат в магнитолу: вкл/выкл** | переключатель таймера |

Все переходы ищутся через `PackageManager` по реальным обработчикам, а не по
жёстко прописанным именам активностей. Поэтому приложение не сломается, если
в прошивке другие имена.

### Автовозврат

Через 6 секунд без нажатий панель сама открывает оболочку магнитолы. Так
«выпасть» из привычного интерфейса невозможно: даже если случайно нажал
«Домой», через несколько секунд вернёшься в магнитолу. Таймер отключается
одной кнопкой (настройка сохраняется).

## Два способа включить

### Способ 1 (быстрый, без перепрошивки) — установить APK

```bash
adb install -r switcher.apk
```

Затем назначить лаунчером. На Android 4.4 диалог выбора лаунчера появляется
при нажатии «Домой», если лаунчер не выбран. Если выбор уже закреплён за
оболочкой Elead:

1. `Настройки → Приложения → Переключатель → «Очистить настройки по умолчанию»`
   (либо `Настройки → Дом`),
2. нажать «Домой» — появится список лаунчеров,
3. выбрать **Переключатель** и «Всегда».

Обратно: на панели нажать «Магнитола» и в диалоге выбрать «Всегда»
(или сбросить настройки по умолчанию у Переключателя).

Установщик APK на устройстве уже есть (`PackageInstaller.apk` на месте),
root тоже (`/system/xbin/su`).

### Способ 2 — вшить в образ (уже сделано)

Приложение лежит в образе как `/system/app/switcher.apk`, поэтому переживёт
сброс данных и доступно сразу после прошивки:

**https://github.com/Stranger-lipetsk/Lifan-X60/actions/runs/41315988466**

| Параметр | Значение |
|---|---|
| Размер | 536 870 912 байт = 512 МиБ |
| Свободно | 273 МиБ |
| sha256 | `915c0add6ec1d222faa8ad493a434791ab4f8c672287f4e89c3a471e0229cb7e` |
| `/system/app/switcher.apk` | 16 879 байт |
| `/system/etc/install-recovery.sh` | 6265 байт, 755 |
| Клавиатура IQQI | на месте |

## Как это выглядит в работе

```
Загрузка ГУ
   ↓
Переключатель (6 с, можно нажать любую кнопку)
   ↓ автовозврат
Оболочка магнитолы  ←→  Стандартный Android (рабочий стол)
        ↕                        ↕
   Радио, BT, камера      Настройки, Wi-Fi, файлы, установка APK
```

Штатный функционал (радио, Bluetooth, камера заднего вида, климат, кнопки руля)
при этом не затрагивается — он живёт в оболочке Elead и продолжает работать.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| После установки чёрный экран вместо лаунчера | `adb shell am start -n tw.com.elead.el830.home/.Home` |
| Не появляется диалог выбора лаунчера | `adb shell pm clear ru.lifan.switcher`, затем «Домой» |
| Панель не отвечает на нажатия | перезагрузка; при повторении — перепрошить штатный образ |
| Нужно вернуть всё как было | удалить `/system/app/switcher.apk` (или `adb uninstall ru.lifan.switcher`) |

Полный откат — штатный образ из архива прошивки, либо `swap.img` из `p6/backup_image`.

## Сборка APK из исходников

```bash
# нужен Android SDK (build-tools + platforms) и JDK 8+
bash switcher/build.sh
# результат: switcher/switcher.apk
```

В репозитории есть CI: `.github/workflows/build-switcher.yml`,
готовый APK — в артефактах запуска «Сборка APK «Переключатель»».
