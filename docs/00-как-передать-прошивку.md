# Как передать прошивку для разбора

У тебя есть 3 удобных способа — выбери любой:

### Вариант 1: Прямо здесь в чате (самый быстрый)
1. Нажми на скрепку 📎 внизу чата Arena
2. Перетащи файл прошивки (`.img`, `.zip`, `.bin`, `.pac`, `.update` и т.д.)
3. Я сразу скачаю её в `firmware/original/` и начну разбор

> Подходит для файлов до ~2 ГБ. Если больше — лучше Вариант 2.

### Вариант 2: Ссылка на облако (для больших прошивок >100 МБ)
Загрузи файл куда удобно и скинь мне ссылку:
- **Яндекс.Диск** (предпочтительно для РФ)
- Google Drive
- Mail.ru Облако
- Любой файлообменник

Я сам скачаю по ссылке в рабочее пространство.

> Не забудь открыть доступ по ссылке: "доступен всем у кого есть ссылка".

### Вариант 3: Через GitHub Desktop (через твой репозиторий)
Так как ты уже установил GitHub Desktop:

1. Открой `Lifan-X60` в GitHub Desktop
2. Скопируй файл прошивки в папку `firmware/original/` на компьютере
   ```
   Lifan-X60/
   └── firmware/
       └── original/
           └── твой_файл.img (или .zip)
   ```
3. В GitHub Desktop увидишь изменения → внизу введи комментарий: `добавлена оригинальная прошивка`
4. Нажми `Commit to arena/b12cc9a8-lifan-x60` → `Push origin`
5. Напиши мне — я увижу пуш и начну работу

> ⚠️ **Важно:** GitHub не любит файлы >100 МБ. Если прошивка больше — GitHub Desktop выдаст ошибку. Тогда используй Вариант 1 или 2.
> Для файлов >100 МБ в репозитории уже настроен Git LFS (`.gitattributes`), но проще кинуть сюда или на Яндекс.Диск.

### Что скинуть вместе с прошивкой?
Чтобы я точно определил железо и максимально возможный Android:

1. **Фото/видео ГУ** — главный экран "О системе" / "About device" (версия Android, ядро, сборка, MCU)
2. **Название файла прошивки** и откуда взял (ссылка на форум, 4PDA, lifan-club и т.д.)
3. **Размер и расширение файла** (например: `update.img 1.2 ГБ`)
4. **Что известно о железе:** процессор (SoC), RAM/ROM, экран, есть ли CAN-bus
5. **Что хочешь получить:** просто обновить Android или + root, + CarPlay, + камера и т.д.

Чем больше инфы — тем точнее смогу поднять версию Android (часто для старых SoC предел 7.1 / 9.0 / 11 из-за драйверов).
