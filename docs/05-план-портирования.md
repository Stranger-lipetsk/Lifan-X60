# План портирования (уточнён после разбора)

Платформа: **Elead EL-830C-LF01 на NXP i.MX6 Solo**, Android 4.4.2, ядро 3.0.35.

## Стратегия A — «модернизация стоковой» (рекомендуется начать с неё)

Цель: выжать максимум из 4.4.2, не рискуя кирпичом.

1. Полный дамп разделов через ADB (root есть): `dd` для `p1..p7`, `mmcblk0boot0`.
2. Собрать образ `system.img` в рабочей папке (ext4, можно монтировать через `debugfs`).
3. Удалить: `Navitel-9.13.73-large.apk` (111 МБ), `IQQIService` (13 МБ), демо-апки,
   неиспользуемые шрифты — освободить ~140 МБ.
4. Добавить: microG (`GmsCore`, `GsfProxy`), обновлённый WebView (Chromium 60+ для ARMv7),
   файловый менеджер, современные плееры.
5. Включить `zram` (512 МБ swap в RAM) и swap на `p2`.
6. Пропатчить `build.prop`: `ro.product.locale=ru_RU`, регион, часовой пояс.
7. Пересобрать `system.img` → положить рядом с `boot.img` на SD → прошить штатным
   механизмом (`sd_boot.img` + скрипты) или через `dd` в `p3`.

Риск: низкий. Откат — `swap.img` из `p6/backup_image`.

## Стратегия B — «портирование BSP 7.1.2» (долгий путь)

1. Взять `android_N7.1.2_2.0.0` (NXP) как базу, ядро 4.1.
2. Создать `device/elead/el830`:
   - `BoardConfig.mk`: `TARGET_BOARD_PLATFORM := imx6`, экран 800×480, `TARGET_ARCH=arm`;
   - device tree на основе i.MX6 Solo + правки под EL830 (пины LCD, eMMC, UART MCU);
   - `init.el_imx6_solo_v2.rc` — перенести сервисы: `mcusync`, `firm_upgrade`,
     `general_conf`, `video_cam`.
3. Драйверы из ядра 3.0.35 переносить в 4.1: `gt9xx`, `elead_gpio`, `adv7283`,
   `tw9990`, `wl12xx` (есть в mainline).
4. Реверс-инжиниринг протокола MCU по `mcusync`/`fw_upgrade` (строки: `magic`, `op_code`,
   `OPCODE_GET_BOARD_FW_INFO`, `OPCODE_START_MCU_UPGRADE` и т.д.) — binutils/radare2.
5. Перенести/переписать приложения Elead под API 25 (камера, радио, BT, климат).
6. Собрать `boot.img` + `system.img`, прошить через SD.

Риск: высокий. Нужен тестовый экземпляр ГУ или готовность к восстановлению.

## Стратегия C — «Android 9» (только при наличии исходников Elead)

Требует ядро 4.9, HAL3 для камеры, HIDL для Wi-Fi/BT. Без вендорских исходников
среднего слоя — экономически нецелесообразно.
