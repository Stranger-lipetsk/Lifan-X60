# До какой версии Android реально поднять это ГУ

## Короткий ответ

| Вариант | Версия | Реалистичность | Комментарий |
|---|---|---|---|
| Теоретический максимум | **Android 9.0** | низкая (месяцы работы) | последний официальный BSP NXP для i.MX6 — `P9.0.0_2.2.0`; ядро 4.9 |
| Практический максимум | **Android 7.1.2** | средняя (недели-месяцы) | BSP `N7.1.2_2.0.0`, ядро 4.1, ещё живёт на 1 ГБ RAM |
| **Рекомендуемый путь** | модернизация стоковой **4.4.2** | **высокая (дни)** | рут уже есть, ставим microG/GMS-lite, новый WebView, чистку, аппы |
| Обход Hardware-лимита | внешний модуль CarPlay/AA | высокая | не повышает Android, но решает задачу «современные приложения» |

## Почему 9.0 — это теория

1. **Ядро 3.0.35** — это 2011 год. Android 8+ (без Treble) требует минимум 4.4,
   с Treble — 4.9. Значит нужно **целиком заменить ядро** на NXP-шное 4.9 из BSP 9.0.
2. Вместе с ядром придётся заново поднять **все драйверы платы**, а исходников нет:
   - `gt9xx.ko` (тачскрин) — только бинарник;
   - `elead_gpio.ko`, `libelead_gpio_runtime.so`, `libelead_video_runtime.so`;
   - Wi-Fi WL12xx (`wl1271-nvs.bin` + калибровка MAC);
   - ADV7283/ADV7280 + `tw9990` (камера заднего хода), OV5640;
   - тюнер tda827x/xc5000, BT-стек Bluesoleil (`/etc/bluesoleil`);
   - обмен с МК (`mcusync`, `fw_upgrade`, протокол с magic/op_code).
3. **Проприетарный средний слой Elead** (`ElSettings`, `elBTService`, `Avin`, `Radio`,
   `IQQIService`) написан под API 19. На Android 9 он не запустится — нужно
   переписать всё, что отвечает за климат/кнопки/камеру/радио.
4. **Camera HAL**: в 4.4 это HAL1, в 8+ нужен HAL3 (camera2). Для аналогового
   декодера ADV7283 придётся писать HAL3-обёртку с нуля.
5. **Железо**: 1× Cortex-A9 1 ГГц, ~1 ГБ RAM (косвенно из `dalvik.vm.heapsize=384m`
   и типового дизайна EL830). Android 9 на такой конфигурации формально запускается,
   но интерфейс будет заметно медленнее текущего 4.4.

## Почему 7.1.2 — практический максимум

- Есть готовый BSP NXP `android_N7.1.2_2.0.0` (i.MX6, ядро 4.1) — драйверы i.MX6
  (IPU, VPU, GPU galcore, SSI, eMMC) в нём уже есть.
- Порог RAM для 7.1 — 1 ГБ (Android Go-режим), 8.0/9.0 — уже 1.5 ГБ для комфорта.
- HAL1 ещё поддерживается (camera), т.е. проще с видеовходом.
- Работы всё равно много: перенос платы EL830 (device tree, экран WVGA, тач GT9xx,
  WL12xx, MCU-протокол, аудио-маршрутизация, реверс `libelead_*`).

**Итог:** цель «Android 7.1.2 с сохранением штатного функционала» — это уже серьёзный
проект уровня «портирование BSP», но реальный. Android 9 — только если найдётся
полный набор исходников от Elead (маловероятно, компания закрытая).

## Что даёт модернизация 4.4.2 (самый быстрый выигрыш)

Устройство уже `userdebug`, `ro.debuggable=1`, с `/system/xbin/su` — рут фактически
штатный. Что можно сделать без замены ядра:

1. **microG вместо GMS** — лёгкий слой для push/локации, работает на 4.4.
2. **Обновить WebView** (сейчас Chromium 33 из 2014) — иначе половина современных
   веб-сервисов и навигаторов не откроется.
3. **TLS 1.2** — включить в `openssl`/WebView, иначе HTTPS к современным сайтам ломается.
4. Вычистить неиспользуемое (`IQQIService` 13 МБ, `Navitel` 111 МБ, демо-апки),
   освободив `/system` и RAM.
5. Настроить swap (раздел `p2` уже есть — 256 МБ) и `zram`.
6. Поставить актуальные навигаторы/плееры с `minSdk ≤ 19` или использовать
   веб-версии через обновлённый WebView.
7. Разблокировать установку APK и ADB-доступ для отладки (уже включён).

Ограничение 4.4: большинство современных приложений требуют `minSdk 21+` (Android 5).
Это и есть главная причина, почему вообще нужен апгрейд.

## Оценка трудозатрат

| Этап | Что делаем | Оценка |
|---|---|---|
| 0 | Бэкап `p6` (`swap.img`, `data.tar`, `config.ini`), дамп всех разделов | 1 вечер |
| 1 | Модернизация 4.4.2 (root, microG, WebView, чистка) | 1–3 дня |
| 2 | Сборка NXP BSP 7.1.2 под EL830: DT, экран, тач, eMMC | 1–3 недели |
| 3 | Wi-Fi/BT/GPS, аудио, MCU-протокол (`mcusync` reverse) | 2–6 недель |
| 4 | Camera HAL для ADV7283, радио-тюнер, кнопки руля/CAN | 2–8 недель |
| 5 | Оболочка Elead (лончер, настройки, климат) — переписать | 2–6 недель |
| 9.0 | Всё то же + ядро 4.9 + Camera HAL3 | ×2 к этапам 2–4 |

## Что нужно от тебя, чтобы двигаться дальше

1. **Фото экрана «О системе»** — подтвердит RAM/eMMC и текущую сборку.
2. **Дамп `p6` (el_data/para_fw)**: `config.ini`, `sys_info.cfg`, `video.cfg`, `tp_verinfo`
   — там серийник, калибровки, версия тача и, возможно, объём памяти.
3. Ответ на вопрос: **готов ли ты к риску** (устройство можно убить, восстановление —
   только через SD-загрузку U-Boot или пайку программатора)?
4. Что важнее: **сохранить штатный функционал** (камера, радио, кнопки) или получить
   свежий Android даже ценой потери части функций?
