# Железо ГУ Lifan X60 FL — установлено по разбору прошивки

> Всё ниже — не догадки: извлечено из `boot.img`, ядра, `u-boot.bin`, `system.img`,
> `MCU_FW.hex` и скриптов прошивки (`build_emmc.sh`, `fw_upgrade`) оригинального архива
> `прошивка офиц. 2016г.rar` (SHA256 `535875d2…`).

## Идентификация устройства

| Параметр | Значение | Источник |
|---|---|---|
| Производитель ГУ | **E-lead Electronic** (Тайвань), сборка `chian@ELEAD-UBUNTU2` | `build.prop`, ядро |
| Модель платы | **EL-830C-LF01** (`el_module=LIFAN_LF01`) | `init.rc` (PRODUCT_MODEL), cmdline |
| Внутреннее имя | `EL_SOLO` / `el_imx6_solo_v2` | `build.prop` |
| SoC | **Freescale/NXP i.MX6 Solo** — 1× Cortex-A9 ARMv7 @ ~1 ГГц | `ro.board.platform=imx6`, ядро |
| GPU | Vivante **GC320** (2D) + GC880-класс (3D), `galcore`, `libg2d.so` | ядро, `/system/lib` |
| Загрузчик | **U-Boot 2009.08** (el_ver 1.4), `ELEAD_BOARD SOLO` | `u-boot.bin` |
| Ядро | **Linux 3.0.35** SMP PREEMPT, gcc 4.6.x-google, сборка 08.06.2017 | распакованный kernel |
| Android | **4.4.2 / API 19**, userdebug, `dev-keys`, SELinux **выключен** | `build.prop`, cmdline |
| Экран | **HANNSTAR WVGA 800×480**, RGB24, 32 bpp, `fbmem=28M` | cmdline `video=mxcfb0` |
| Носитель | **eMMC** через `sdhci-esdhc-imx.2` (mmc0) + бут-раздел `mmcblk0boot0` | `build_emmc.sh` |
| Слот SD | `mmc1` (sdhci-esdhc-imx.3) — используется и для прошивки | fstab |
| USB | 2 порта host (`fsl-ehci.1`: usb1, usb2) + OTG | fstab |

## Периферия (драйверы в ядре/системе)

| Узел | Чип / драйвер | Примечание |
|---|---|---|
| Тачскрин | **Goodix GT9xx** (`gt9xx.ko`), версия из `/proc/gt9xx_ver` | калибровочный файл `eGTouchA_v2.5.2112.A-a.ini` |
| Wi-Fi + BT | **TI WiLink (WL1271/WL12xx)** — `wl1271-nvs.bin`, калибровка MAC в `para_fw` | `set_wl12xx_wifi_calibration` в `fw_upgrade` |
| GPS | модуль **AMPAK** + NMEA (`ELEAD_AMPAK_GPS_RST`) | сброс по GPIO |
| Камера (заднего хода) | аналоговый декодер **ADV7283/ADV7280** + `tw9990` | + **OV5640** как основной сенсор превью |
| FM-радио | тюнер **tda827x / xc5000**, `tef6638` (dummy codec) | приложение `EL831CLF01_Radio` |
| Аудио | i.MX SSI + `libimx6-tinyplayer.so`, `libimx6-btaudioctl.so` | ALSA tinyalsa |
| MCU (климат/кнопки/питание) | **отдельный МК**, прошивка `MCU_FW.hex` (Intel HEX, 73 КБ) | обмен по UART, демон `mcusync` |
| GPIO/подсветка/питание | `elead_gpio.ko`, `libelead_gpio_runtime.so` | проприетарный HAL |
| Видео-ускоритель | i.MX **IPU/VPU**, `libelead_video_runtime.so` | v4l2 + VPU firmware |

> Вывод: **это не Rockchip PX3/PX5** (как у большинства китайских ГУ), а промышленная
> платформа на i.MX6 с проприетарным средним слоем Elead. Это принципиально меняет
> стратегию портирования — см. [04-макс-версия-android.md](04-макс-версия-android.md).

## Разметка eMMC (из `build_emmc.sh`)

Скрипт `sfdisk --force -uM` задаёт разделы в мегабайтах:

| Раздел | Смещение/размер | Назначение |
|---|---|---|
| `mmcblk0boot0` | — | **U-Boot** (`dd if=u-boot.bin of=/dev/block/mmcblk0boot0`) |
| `p1` | 8 МБ резерв + 8 МБ | **boot.img** |
| `p2` | 256 МБ, ext4 | **swap.img** — снапшот системы для быстрого восстановления |
| `p3` | 512 МБ, ext4 | **system.img** (занято ~360 МиБ) |
| `p4` | остальное | расширенный раздел |
| `p5` | 512 МБ, ext4 | **data** (пользовательские данные) |
| `p6` | 384 МБ, ext4 | **el_data / para_fw**: `config.ini`, `sys_info.cfg`, `video.cfg`, `tp_verinfo`, `backup_image/` |
| `p7` | остаток, FAT32 | **карты Navitel** (`/Navngo`) |

## Программный состав `system.img`

- 1341 файл, 51 APK, ~360 МиБ, ext4.
- **Google-сервисов нет** — чистый AOSP без Play Market и GMS.
- Навигация: **Navitel 9.13.73** (111 МБ), карты отдельно на `p7`.
- Оболочка Elead: `EL830LF01_Home.apk` (лончер), `ElSettings.apk` (настройки, 4 МБ),
  `EL831CLF01_Avin` (видеовход/камера), `Radio`, `MediaPlayer`,
  комплект Bluetooth (`elBTService`, `elBluetoothPhone/Music/Dial/Setup`),
  `IQQIService` (клавиатура), `EL830TAM1_GPIO_TEST` (инженерный тест GPIO).
- **`/system/xbin/su` и `/system/bin/su` присутствуют**, `ro.debuggable=1`, ADB включён
  по умолчанию ⇒ устройство уже рут-способно на стоковой прошивке.
