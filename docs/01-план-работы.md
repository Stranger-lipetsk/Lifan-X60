# План разбора и портирования прошивки Lifan X60 FL

## Цель
Разобрать штатную прошивку ГУ Lifan X60 FL, определить SoC/плату/периферию и собрать кастомную прошивку с максимально возможной версией Android для этого железа.

## Этапы

### 1. Приём и верификация оригинала
- [ ] Получить файл(ы) прошивки в `firmware/original/`
- [ ] Посчитать `sha256sum`, `file`, `binwalk`, `strings`
- [ ] Определить формат: Rockchip `.img`, Allwinner `.img`, MStar, MTK `scatter.txt`, Spreadtrum `.pac`, обычный `update.zip`

### 2. Распаковка
- [ ] Распаковать внешнюю оболочку: `unzip`, `7z`, `imgextractor`, `rkImgExtractor`, `Allwinner ImgRePacker`
- [ ] Достать разделы: `boot.img`, `recovery.img`, `system.img`, `vendor.img`, `uboot`, `kernel`, `mcu.bin`
- [ ] Размонтировать `system.img`: `simg2img` → `mount` / `7z` / `ext4extract`
- [ ] Разобрать `boot.img`: `magiskboot` / `abootimg` → `kernel`, `ramdisk`, `dtb`, `cmdline`

### 3. Анализ железа
- [ ] `build.prop` / `default.prop`: `ro.product.board`, `ro.build.version.sdk`, `ro.kernel.version`
- [ ] `dmesg`, `kernel config`, `Device Tree` (`.dtb` → `.dts`)
- [ ] Драйверы: WiFi, BT, GPS, радио (TDA7xxx), усилитель, MCU, CAN, камера ЗХ
- [ ] SoC идентификация: RK3066/PX3/PX5/PX6, Allwinner T3/T8, MT3561, AC8227L и т.д.
- [ ] RAM/ROM, тип экрана, тач-контроллер

### 4. Оценка максимальной версии Android
Критерии:
- Версия ядра: 3.4 → макс Android 7.1, 3.18 → 8/9, 4.4 → 9/11, 4.14+ → 12/13
- Наличие BSP/драйверов от производителя SoC
- Доступные LineageOS / Halium порты для этого SoC
- Требования к RAM: <1ГБ → Android Go only

Составить таблицу: `чистая AOSP` vs `LineageOS` vs `аналог от Malaysk/Hal9k` для PX-платформ.

### 5. Выбор стратегии сборки
Варианты по приоритету:
1. **Портирование готовой прошивки** от донора с тем же SoC (самый реальный путь для МТХ/PX)
2. **Сборка AOSP/LineageOS** из исходников + vendor blobs из оригинала
3. **Мод стоковой** (деодекс, рут, gapps, обновление WebView, патч безопасности) если ядро не поднять

### 6. Сборка и тестирование
- [ ] Подготовить `device/lifan/x60` дерево
- [ ] Собрать `boot.img` + `system.img`
- [ ] Сгенерировать `update.zip` / `RK batch image` совместимый со штатным recovery
- [ ] Инструкция по прошивке + откату (бэкап!)
