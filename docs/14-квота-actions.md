# Квота GitHub Actions и артефакты

## Что произошло

Пришло предупреждение: **«You have used 100% of the Actions storage»**.
Причина — не образ прошивки, а аналитические прогоны.

| Артефакт | Кол-во | Объём |
|---|---|---|
| `firmware-reports` | 41 | **22 454 МБ** |
| `system-img-lite` | 10 | 1 295 МБ |
| `deep2-reports` | 1 | 419 МБ |
| `deep-reports` | 1 | 32 МБ |
| прочее | 5 | < 1 МБ |
| **Итого** | **58** | **~24 ГБ** |

Каждый прогон анализа заливал папку `reports/` в артефакт, а там лежали
распакованные образы (`system.img` 377 МБ, ядро, ramdisk). При этом те же
отчёты **всегда коммитились в репозиторий** — артефакт был чистым дубликатом.

## Что сделано

1. **Удалены все старые артефакты.** Остался один — актуальный
   `system-img-lite` из прогона, который нужен для прошивки.
   Итого: было ~24 ГБ, стало **129 МБ**.

2. **Отключена заливка отчётов в артефакты** во всех аналитических workflow
   (`firmware-analyze`, `firmware-deep-analyze`, `firmware-deep2`,
   `firmware-pass3`). Отчёты по-прежнему коммитятся в `reports/` — они никуда
   не делись, вся история анализа доступна в репозитории.

3. **Добавлен workflow `cleanup-artifacts.yml`** — ручная очистка.

## Как чистить вручную

Очистка запускается пушем маркера (GitHub не даёт запускать `workflow_dispatch`
с ветки, отличной от основной):

```bash
echo "cleanup $(date -u +%FT%TZ)" > autoanalysis/cleanup.txt
git commit -am "chore: очистка артефактов"
git push
```

По умолчанию удаляется всё, **кроме свежего `system-img-lite`**.
Можно задать параметры через `workflow_dispatch` (из основной ветки):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `keep_days` | `0` | удалить артефакты старше N дней |
| `keep_image` | `1` | сохранить свежий образ |

## Что теперь остаётся в артефактах

| Workflow | Артефакт | Размер |
|---|---|---|
| Сборка лайт-образа | `system-img-lite` | ~129 МБ |
| Сборка APK | `switcher-mirrorlink-apk` | ~12 КБ |

Аналитические прогоны не оставляют ничего — только коммиты в `reports/`.

## Сколько прогонов можно держать

Бесплатная квота хранилища Actions — 500 МБ. Реальные цифры:

| Что | Объём | Сколько влезает |
|---|---|---|
| образ `system-img-lite` | 129 МБ | ~3 прогона |
| APK переключателя | 12 КБ | практически без ограничений |

**Практическое правило:** держать один образ. Перед новой сборкой старый
перезаписывается — GitHub сам удаляет артефакты с тем же именем при повторной
загрузке? Нет, не удаляет: имя с суффиксом не меняется, но **новый прогон
создаёт новый артефакт**. Поэтому периодически запускай очистку.

Либо скачивай образ сразу после сборки и запускай очистку — держать его
в GitHub постоянно смысла нет.

## Если квота снова кончится

```bash
# посмотреть, что занимает место
gh api "/repos/Stranger-lipetsk/Lifan-X60/actions/artifacts?per_page=100" \\
  --jq '.artifacts | group_by(.name) | map({name:.[0].name, mb:(map(.size_in_bytes)|add/1048576|floor)}) | .[]'
```

Затем — очистка (см. выше). Код и отчёты при этом не страдают: они в git.
