# Как скачать готовую прошивку

## Готовый прогон

**https://github.com/Stranger-lipetsk/Lifan-X60/actions/runs/41318480827**

| Параметр | Значение |
|---|---|
| Размер образа | 536 870 912 байт = ровно 512 МиБ |
| sha256 | `b333fa8a4e9c8ad941b3b8bfec71240b9b460fdddc96b7fe9e1688f54d86f651` |
| Свободно | 273 МиБ (`Free blocks 70028`) |
| Артефакт | `system-img-lite` (135 865 505 байт — zip) |
| `/app/com.fpt.mirrorlink.android.apk` | 16 879 байт, 0644, root:root |
| `/etc/install-recovery.sh` | 6265 байт, 0755 |
| Клавиатура IQQI | на месте |

## Способ 1: через браузер (проще всего)

1. Открой ссылку прогона выше.
2. Прокрути страницу вниз до блока **Artifacts** (в самом низу).
3. Нажми **`system-img-lite`** — скачается `system-img-lite.zip`.
4. **Распакуй** архив — внутри лежит `system.img`.
5. Проверь файл (обязательно, см. ниже).

### Важно: нужен вход в GitHub

Скачивание артефактов доступно **только авторизованному пользователю** —
это настройка самого GitHub, для приватных и публичных репозиториев одинаково.
Так как ты уже владелец репозитория, просто убедись, что вошёл в аккаунт
`Stranger-lipetsk` в браузере.

Если архив не скачивается («Sign in to download») — проверь вход.
Если кнопки нет вовсе — прогон старше 90 дней (артефакты удаляются), тогда
запусти сборку заново:

**Actions → «Сборка лайт-образа (итоговая)» → Run workflow**

Либо сделай любой коммит в файл `autoanalysis/buildlite.txt` — сборка
запустится сама.

---

## Способ 2: через GitHub Desktop

GitHub Desktop **не умеет** скачивать артефакты Actions — он работает только
с файлами репозитория. Образ весит 512 МиБ, в git его не кладём.

Поэтому: скачивание — через браузер (способ 1), а **коммиты и правки** —
через GitHub Desktop, как обычно.

---

## Способ 3: командная строка (если есть Git Bash)

```bash
# нужен GitHub CLI: https://cli.github.com
gh run download 41318480827 -R Stranger-lipetsk/Lifan-X60 -n system-img-lite
```

Появится папка с `system.img` внутри.

---

## Проверка файла после скачивания

Обязательно сверь sha256 — это гарантия, что файл дошёл целым и это именно
собранный образ.

**Windows (PowerShell):**
```powershell
Get-FileHash system.img -Algorithm SHA256
```

**Windows (Git Bash) / Linux / macOS:**
```bash
sha256sum system.img
```

Должно получиться:

```
b333fa8a4e9c8ad941b3b8bfec71240b9b460fdddc96b7fe9e1688f54d86f651
```

Если не совпало — файл побился при скачивании, скачай заново. **Прошивать
такой образ нельзя.**

Дополнительно можно проверить размер:

| Система | Команда | Ожидание |
|---|---|---|
| Windows | `(Get-Item system.img).Length` | `536870912` |
| Linux/macOS | `stat -c%s system.img` | `536870912` |

## Что ещё понадобится для прошивки

Образ — это только раздел `system`. Для прошивки на флешку нужно положить
ещё несколько файлов **из заводского архива** (они не менялись):

| Файл | Откуда | Менять? |
|---|---|---|
| `system.img` | **скачанный артефакт** | это наш новый |
| `boot.img` | заводской архив прошивки | ❌ не трогать |
| `u-boot.bin` | заводской архив | ❌ не трогать |
| `MCU_FW.hex` | заводской архив | ❌ не трогать |
| `sd_boot.img` | заводской архив | ❌ **ни в коем случае** (загрузчик обновления) |

Заводской архив: **https://disk.yandex.ru/d/qJdjjeB8Aiq3Lg**
(файл с `2016` в названии, ~377 МБ `system.img` внутри).

Порядок прошивки подробно — в
[docs/06-инструкция-модернизации.md](06-инструкция-модернизации.md),
раздел «Прошивка результата».

## Перед прошивкой: сохрани бэкап

Прошивка **пересоздаёт таблицу разделов** и стирает пользовательские данные.
В разделе `p6` лежит калибровка тача (`tp_verinfo`) и `swap.img` для откатa.
Скрипт для дампа:

```bash
bash tools/backup-device.sh
```

Без бэкапа откатиться будет нечем, а калибровку тача можно потерять.

## Если скачивание не работает

| Симптом | Причина | Решение |
|---|---|---|
| «Sign in to download» | не выполнен вход в GitHub | войти под `Stranger-lipetsk` |
| Кнопки `system-img-lite` нет | прогон старше 90 дней | запустить сборку заново (см. способ 1) |
| Скачался, но не открывается | недокачался | скачать заново, сверить sha256 |
| Не совпал sha256 | битая передача | скачать заново; если повторяется — скачать через `gh run download` |
| `system.img` не внутри архива | скачался другой артефакт | нужен именно `system-img-lite` |
