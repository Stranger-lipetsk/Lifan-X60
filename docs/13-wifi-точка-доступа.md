# Wi-Fi точки доступа телефона на этой магнитоле

Штатного модема в ГУ нет — интернет только через Wi-Fi. Ниже проверено по образу
и ядру, что именно поддерживается и где подводные камни.

## Какой Wi-Fi-чип на самом деле

В отчётах раньше было противоречие, поэтому проверил распаковкой ядра:

```
=== вхождения драйверов Wi-Fi (ядро 3.0.35, распаковано 7.6 МБ) ===
  bcmdhd         0        ← Broadcom-драйвера НЕТ
  wl12xx         6        ← ЕСТЬ
  wl1271         0
  wlcore         0

контекст: ...wl12xx_get_platform_data...  (TI WiLink)
```

**Чип: TI WiLink (wl12xx / WL1271).** Драйвер вкомпилирован в ядро.

А файлы `nvram.txt` (`/etc/wifi`) и `fw_bcm40181a2.bin` (`/etc/firmware`) —
это **остатки от базовой AOSP-сборки Broadcom**, они не используются. Путаницы
они не создают, но и на чип не указывают.

### Что это значит на практике

| Параметр | WL1271 | Следствие |
|---|---|---|
| Диапазон | **только 2.4 ГГц** | 5 ГГц **не увидит вообще** |
| Стандарты | 802.11 b/g/n | — |
| Шифрование | WPA2-PSK (AES/TKIP) | WPA3 не поддерживается |
| Точка доступа (hotspot) | умеет (`hostapd` в системе) | можно раздавать с ГУ |

## Главное: точка доступа должна быть на 2.4 ГГц

Современные телефоны часто включают хотспот на 5 ГГц или в режиме «авто».
ГУ такой сети **не увидит**, и это будет выглядеть как «Wi-Fi не работает».

**Android:** Настройки → Точка доступа → Диапазон → **2.4 ГГц**
**iPhone:** Настройки → Режим модема → «Максимальная совместимость» → вкл

Дополнительно:

| Настройка | Значение |
|---|---|
| Диапазон | **2.4 ГГц** (обязательно) |
| Канал | 1–11 (не «авто» выше 11) |
| Защита | **WPA2-PSK**, AES |
| Имя сети (SSID) | латиница, без пробелов и эмодзи |
| Скрытая сеть | **выключить** (скрытые сети хуже ловятся) |

## Подводный камень: калибровка Wi-Fi в `para_fw` стирается при прошивке

Нашёл в `fw_upgrade` (заводская утилита обслуживания):

```
set_wl12xx_wifi_calibration
get_wl12xx_wifi_mac
/mnt/para_fw/wl1271-nvs.bin     ← калибровка + MAC чипа
/mnt/extsd/wl1271-nvs.bin       ← копия на SD-карте
```

Файл `wl1271-nvs.bin` — это NVS-калибровка радио и **MAC-адрес Wi-Fi**.
Он лежит в `p6` (`/mnt/para_fw`), а `p6` при прошивке **форматируется**.

При этом `backup_operation` сохраняет только `config.ini` — NVS в этот список
не входит. Утилита `fw_upgrade` ищет копию на SD-карте
(`/mnt/extsd/wl1271-nvs.bin`), то есть **рассчитывает, что ты её туда положишь**.

### Что будет, если не сохранить

- Скорее всего Wi-Fi заработает — калибровка пересоздастся
  (`set_wl12xx_wifi_calibration`), но MAC-адрес станет другим.
- Если у тебя есть фильтрация по MAC на роутере/телефоне — придётся добавлять заново.
- В худшем случае радио поднимется с дефолтной калибровкой: слабее сигнал,
  возможны обрывы.

### Что сделать перед прошивкой

```bash
# 1. забрать калибровку себе
adb pull /mnt/para_fw/wl1271-nvs.bin ./wl1271-nvs.bin

# 2. положить копию в корень SD-карты с прошивкой — туда смотрит fw_upgrade
#    (файл должен называться ровно wl1271-nvs.bin)
```

Это единственное, что нужно для Wi-Fi. Тридцать секунд работы.

## Как подключиться к точке доступа

1. **MirrorLink** на главном экране ГУ (наша панель)
2. Кнопка **«Настройки Wi-Fi»**
3. Включить Wi-Fi, выбрать сеть телефона, ввести пароль
4. Проверить: **«Настройки Android»** → раздел Wi-Fi показывает «Подключено»

Доступ к этим экранам есть только через нашу панель — в штатной оболочке
Elead к Wi-Fi не пройти. Это ровно та задача, которую мы решали.

## Если сеть не находится

| Симптом | Причина | Решение |
|---|---|---|
| Список сетей пуст | Wi-Fi выключен или драйвер не поднялся | включить в настройках; `adb shell dumpsys wifi \| head` |
| Сеть телефона не видна | хотспот на **5 ГГц** | переключить на 2.4 ГГц |
| Сеть видна, но не подключается | WPA3 или WPA2/WPA3 mixed | поставить чистый WPA2-PSK (AES) |
| Постоянно «Получение IP» | DHCP не отвечает | перезагрузить ГУ, перезапустить хотспот |
| Подключилось, интернета нет | на телефоне нет мобильных данных или включён запрет | проверить на телефоне |
| Отваливается через минуту | экономия энергии Wi-Fi | «Настройки Android» → Wi-Fi → «Дополнительно» → «Wi-Fi в спящем режиме» → «Никогда» |

### Посмотреть, что происходит

```bash
adb shell dmesg | grep -i wl12
adb shell logcat -s wpa_supplicant:V WifiStateMachine:V
adb shell dumpsys wifi | head -40
```

Если в `dmesg` пусто про `wl12` — драйвер не загрузился, это про NVS
(см. раздел выше).

## Сколько трафика уходит на пробки

| Задача | Расход |
|---|---|
| Яндекс Навигатор с пробками (1 час) | ~5–15 МБ |
| Пробки + карта онлайн | ~15–30 МБ/час |
| Обновление карт | 100–500 МБ разово |
| Navitel (офлайн-карты) | 0 |

Среднестатистическая езда 1–2 часа в день → **около 1 ГБ в месяц**.
Хватает обычного тарифа. Если трафик ограничен — держи карты Навигатора
скачанными офлайн, тогда онлайн идут только пробки (самый дешёвый вариант).

## Что учесть про сам телефон

- Хотспот на телефоне **сажает батарею** — держи телефон на зарядке в машине.
- Некоторые операторы блокируют раздачу или считают её отдельно.
- Если телефон раздаёт и 2.4, и 5 ГГц под одним именем — ГУ подключится
  к 2.4 автоматически, но лучше разделить имена (`MyPhone` и `MyPhone_5G`).
- ГУ остаётся в сети и на стоянке: Wi-Fi не выключается по умолчанию.
  Если нужно — в настройках Wi-Fi отключи автоподключение.

## Проверка «всё готово» перед прошивкой

```bash
# 1. сохранить калибровку Wi-Fi (см. выше)
adb pull /mnt/para_fw/wl1271-nvs.bin ./wl1271-nvs.bin

# 2. посмотреть текущий MAC, чтобы сверить после прошивки
adb shell cat /sys/class/net/wlan0/address
```

После прошивки:

```bash
adb shell cat /sys/class/net/wlan0/address   # сравнить с сохранённым
```

Если MAC тот же — калибровка восстановилась. Если другой, но Wi-Fi работает —
не страшно, просто обнови фильтр на роутере.
