## Главное ограничение: версия приложения

Последняя версия Яндекс Навигатора с поддержкой Android 4.4 — **6.40**
(сборка `6409671` для ARMv7, ноябрь 2021, 98.77 МБ). Всё, что новее,
требует Android выше.

| Версия | Мин. Android | Годится? |
|---|---|---|
| **6.40** (arm-v7a) | 4.4 | **да, последняя рабочая** |
| 5.51 / 5.60 | 4.4 | да, если 6.40 будет глючить |
| 4.40 | 4.2 | да, самая старая из «новых» |
| 18.4.0 | 6.0 | нет |
| 29.x / 30.x (текущие) | 8.0+ | нет |

Пакет: `ru.yandex.yandexnavi`. Где брать: APKMirror, раздел
«Yandex Navigator (Android 4.4+)» — фильтр `minapi-19`, архитектура
**armeabi-v7a**.

## Что может помешать

### 1. TLS и WebView

Прошивка 2016 года, WebView — Chromium 33. Яндекс использует свой HTTP-стек
(`OkHttp`), а не WebView, поэтому запросы к серверам идут не через него.
Но если Яндекс обновит требования к TLS на серверах, старые клиенты могут
перестать получать данные о пробках.

**Практика:** версии 5.x–6.x на 4.4 у людей работают, но это не гарантия на
годы вперёд. Если пробки перестанут грузиться — дело в этом, а не в тебе.

### 2. Экран 800×480 (WVGA), плотность 160

Интерфейс Яндекс Навигатора рассчитан на телефоны. На WVGA возможны:

- мелкие элементы, которые трудно нажать на ходу;
- обрезанные диалоги (кнопки «ОК» уходят за край).

**Решение:** в самом Навигаторе есть настройка размера интерфейса
(«Настройки → Внешний вид»). Если её нет в 6.40 — помогает `wm density`
или `wm size`:

```bash
adb shell wm size 800x480
adb shell wm density 140     # крупнее элементы
# вернуть: adb shell wm density reset
```

### 3. Память

i.MX6 Solo с 1 ГБ ОЗУ, из которых системе остаётся меньше. Навигатор с
онлайн-картами — тяжёлое приложение. Возможны подтормаживания при
перерисовке карты.

**Что помогает** (уже в нашем образе): освобождено 273 МиБ в `/system`,
удалены фоновые приложения. Дополнительно можно включить `zram` — но это
отдельная доработка.

### 4. Первый запуск требует сети

При первом старте Навигатор скачивает служебные данные. Значит:

1. сначала подключи Wi-Fi (MirrorLink → «Настройки Wi-Fi»);
2. потом запускай Навигатор.

Без сети приложение откроется, но карта может не загрузиться.

## Порядок действий после прошивки

```bash
# 1. Установить APK (версия 6.40 arm-v7a)
adb install -r YandexNavi-6.40-armeabi-v7a.apk

# или с флешки: MirrorLink → «Файловый менеджер» → выбрать APK
# (понадобится разрешить «Неизвестные источники»)

# 2. Проверить, что GPS видит спутники
adb shell dumpsys location | head -30
# либо любым приложением GPS Test

# 3. Подключить Wi-Fi
#    MirrorLink → «Настройки Wi-Fi» → выбрать сеть

# 4. Запустить Навигатор, дать разрешения, проверить пробки
```

## Если GPS не ловится

Приёмник есть, но антенна и её подключение — вопрос к конкретной машине.
Проверка:

```bash
adb shell dumpsys location
adb shell logcat -s GpsLocationProvider:V gps:V
```

Если в логе видно `NMEA` строки — приёмник работает, дело в приложении.
Если тишина — смотри антенну GPS (обычно под панелью).

Оптимально держать **два навигатора**:

- **Navitel** — основной, офлайн-карты, работает без сети;

ставить их лучше на `data` или на внешний накопитель — тогда `/system`
останется свободным.
