## Как проходит штатное обновление (установлено из скриптов)

`sd_boot.img` — это не обычный recovery, а **загрузочный образ с полной копией новой
системы внутри** (ramdisk распаковывается в 45 МБ и содержит `/system/…`).

1. Флешка (FAT32) с файлами архива вставляется в слот SD.
2. U-Boot видит `sd_boot.img` (`fatload mmc 3 0x20000000 sd_boot.img` → `booti mmc2`).
3. Стартует recovery, ядро монтирует раздел с флешки как `/fw_data` (fstab: `mmcblk1p1 /fw_data vfat`).
4. Сервис `firm_upgrade` (`/system/bin/fw_upgrade`) по команде с ГУ запускает
   дочерний процесс и пишет прогресс в `/dev/temp/fw_status.cfg`
   (`proc_start`, `format_partition`, `unzip_maps`, `proc_finished`, `proc_error`).
5. `build_emmc.sh` (с правами root):
   - бэкапит `config.ini` с `p6`;
   - **пересоздаёт таблицу разделов** через `sfdisk`;
   - форматирует `p2, p3, p5, p6` в ext4, `p7` в FAT32;
   - пишет `u-boot.bin` в `mmcblk0boot0`, `boot.img` → `p1`, `system.img` → `p3`;
   - восстанавливает `config.ini`, распаковывает карты Navitel в `p7`.
6. Быстрое восстановление: `swap.img` (снапшот в 256 МБ) кладётся на `p2`,
   а копия остаётся в `p6/backup_image/` — `boot_mode_check.sh` при проблемах
   автоматически разворачивает её обратно (по флагу `/proc/el_boot_mode`).

> ⚠️ **Важно для экспериментов:** штатная прошивка **пересоздаёт таблицу разделов** и
> **стирает пользовательские данные**. Любой кастомный вариант надо делать так же
> (или аккуратно переписывать только `p3`), иначе получим кирпич.

## Загрузочная цепочка

```
BootROM i.MX6 → mmcblk0boot0 (U-Boot 2009.08, el_ver 1.4)
      → booti mmc2 → p1 (boot.img: zImage 3.0.35 + ramdisk)
      → /system (p3) → Android 4.4.2 → Home.apk (оболочка Elead)
```

Параметры cmdline (подтверждают железо):

```
console=ttymxc0,115200 init=/init
video=mxcfb0:dev=lcd,HANNSTAR-WVGA,if=RGB24,fbpix=RGB32,bpp=32
fbmem=28M vmalloc=400M lpj=7905280
androidboot.selinux=disable panic=3
el_module=LIFAN_LF01
```

## Замечания по безопасности и «кирпиче»

- Есть **быстрый откат**: `swap.img` + `data.tar` в `p6/backup_image/` — сохранить себе
  копию `p6` перед экспериментами.
- Восстановление при полном отказе: U-Boot умеет грузиться с SD (`fatload mmc 3`),
  то есть даже при убитом eMMC устройство поднимается с карты — это спасает.
- `MCU_FW.hex` — **не трогать** через Android. Обновляется только через `fw_upgrade`
  (`OPCODE_START_MCU_UPGRADE`), иначе можно остаться с нерабочими кнопками/питанием.
