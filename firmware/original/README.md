# firmware/original

Сюда кладём **оригинальные** файлы прошивки ГУ Lifan X60 FL без изменений.

## Как добавить

### Через чат Arena (рекомендуется)
Перетащи файл прямо в чат — я сам положу его сюда.

### Через облако
Скинь ссылку на Яндекс.Диск / Google Drive — я скачаю.

### Через GitHub Desktop
1. Скопируй файл в эту папку на ПК
2. Commit → Push

> Если файл >100 МБ — лучше чат или облако, GitHub может не пропустить без LFS.

## После добавления
Запусти/попроси меня запустить:
```bash
./tools/analyze.sh firmware/original/твой_файл.img
```
Скрипт создаст отчёт в `docs/отчеты/`.

## Что сейчас внутри
Пока пусто — ждём твою прошивку.

Формат имени для порядка:
```
lifan-x60-fl-stock-<версия>-<дата>.img
lifan-x60-fl-stock-<версия>-<дата>.zip
```
