# Сюда — APK приложений

Положи сюда три файла (имена важны только для Navitel — см. ниже):

| Файл | Что это | Куда попадёт в системе |
|---|---|---|
| `Navitel-11.11.1110.apk` | Navitel 11.11.1110 | `/priv-app` |
| `YandexNavigator-6.40.apk` | Яндекс Навигатор 6.40 (для Android 4.4) | `/app` |
| `TorquePro.apk` | Torque Pro | `/app` |

Правила:
- если в имени файла есть «avitel» — APK ставится в `/priv-app`, остальные в `/app`;
- имя файла в системе не важно, важно имя пакета внутри APK;
- файлы попадут в образ, а не в git-историю приложения.

Скачивать ничего не нужно из CI: она берёт APK прямо отсюда.
