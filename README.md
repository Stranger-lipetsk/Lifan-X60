# Lifan X60 — кастомная прошивка ГУ (FL)

Разбор штатной прошивки головного устройства Lifan X60 FL и создание кастомной прошивки с максимально возможной версией Android для данного железа.

## Быстрый старт

**Есть прошивка на руках?**

1. Смотри инструкцию: [`docs/00-как-передать-прошивку.md`](docs/00-как-передать-прошивку.md)
2. Самый простой способ — перетащи файл прямо в чат Arena сюда
3. Или скинь ссылку на Яндекс.Диск / Google Drive
4. Или залей через GitHub Desktop в `firmware/original/`

## Структура репозитория

```
Lifan-X60/
├── docs/
│   ├── 00-как-передать-прошивку.md  ← начни отсюда
│   ├── 01-план-работы.md
│   └── отчеты/                      ← сюда попадут отчёты анализа
├── firmware/
│   ├── original/                    ← оригинальные прошивки (LFS)
│   └── unpacked/                    ← распакованное (не коммитится)
├── tools/
│   └── analyze.sh                   ← автоанализ прошивки
└── README.md
```
