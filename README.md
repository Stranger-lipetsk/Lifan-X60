# Lifan X60 FL — разбор и модернизация ГУ (Elead EL-830C-LF01)

Разбор штатной прошивки головного устройства Lifan X60 FL и подготовка
кастомной прошивки с максимально возможной версией Android для этого железа.

## Что уже выяснено (по факту разбора)

| | |
|---|---|
| **Платформа** | E-lead **EL-830C-LF01**, NXP **i.MX6 Solo** (1× Cortex-A9) |
| **Android** | **4.4.2 / API 19**, userdebug, SELinux off, **root доступен** |
| **Ядро** | Linux **3.0.35** (2017), U-Boot 2009.08 |
| **Экран** | HANNSTAR WVGA **800×480**, RGB24 |
| **Периферия** | тач Goodix GT9xx, Wi-Fi/BT TI WL12xx, GPS AMPAK, камера ADV7283+OV5640, FM tda827x/xc5000, отдельный МК по UART |
| **Носитель** | eMMC, 7 разделов, разметка задаётся скриптом `build_emmc.sh` |
| **GMS** | отсутствует (чистый AOSP), навигация Navitel 9.13.73 |

Подробно: [docs/02-железо.md](docs/02-железо.md) · [docs/03-состав-прошивки.md](docs/03-состав-прошивки.md)

## Задача: штатный функционал + свои приложения (решено на 4.4.2)

Требования: сохранить заводские функции, получить установку APK, поставить
**Torque Pro** и обновить **Navitel**.

| Что | Требует | Подходит на 4.4.2 |
|---|---|---|
| Torque Pro (`org.prowl.torque`) | Android 4.1+ | ✅ |
| Navitel 11.11.1128 (официально для 4.4–5.1) | Android 4.4+ | ✅, тот же пакет `com.navitel` |

Инструкция: **[docs/06-инструкция-модернизации.md](docs/06-инструкция-модернизации.md)**
Как скачать готовый образ: **[docs/09-как-скачать-образ.md](docs/09-как-скачать-образ.md)**
Доступ к Android, Wi-Fi и файлам: **[docs/08-mirrorlink-vyhod-k-android.md](docs/08-mirrorlink-vyhod-k-android.md)**
Сборка образа: `python3 tools/build_system.py --fw архив.rar --out out/system.img ...`

## Потолок версии Android

- **Теоретический максимум — Android 9.0** (последний BSP NXP для i.MX6), но требует
  замены ядра на 4.9 и переписывания всех проприетарных слоёв Elead.
- **Практический максимум — Android 7.1.2** (BSP `N7.1.2_2.0.0`, ядро 4.1).
- **Быстрый выигрыш — модернизация стоковой 4.4.2**: root уже есть, ставим microG,
  обновляем WebView/TLS, чистим и ускоряем.

Обоснование и трудозатраты: [docs/04-макс-версия-android.md](docs/04-макс-версия-android.md) ·
План работ: [docs/05-план-портирования.md](docs/05-план-портирования.md)

## Следующие шаги

1. Сделать бэкап разделов с устройства: [`tools/backup-device.sh`](tools/backup-device.sh)
2. Прислать дамп `p6` (para_fw: `config.ini`, `sys_info.cfg`, `video.cfg`, `tp_verinfo`)
3. Фото экрана «О системе» — подтвердить RAM и объём eMMC
4. Собрать «лайт»-образ system (Стратегия A)

## Важно

> Штатная прошивка **пересоздаёт таблицу разделов** и стирает данные.
> Перед экспериментами сохрани `p6/backup_image` (`swap.img`, `data.tar`) — это
> штатный механизм быстрого восстановления.
> `MCU_FW.hex` не трогать иначе как через `fw_upgrade`.
