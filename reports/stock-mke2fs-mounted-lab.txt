# Stock-derived ARM mke2fs against an isolated synthetic mounted loop device
Offline CI-only Linux/QEMU user-mode restricted container with synthetic empty Android property area; no actual GU, Android kernel, physical partition, user files, or hibernation script.
Stock-derived mke2fs SHA-256: 45b4cad925fe740a013f64192f6ba09784038b4b9dca4f5f1a3ed37f1a364c3e.
Positive control: exact binary formatted a blank unmounted 64 MiB file-backed loop, then read-only e2fsck succeeded.
The same image was then mounted read-write in the CI host and exposed as a mounted filesystem and the same loop device inside the restricted container.
Invocation without -F and with no interactive input: mke2fs -t ext4 synthetic-loop; exit 1.
