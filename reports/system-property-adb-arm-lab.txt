Disposable emulator; no head unit, real storage, user data, or user network accessed.
Host firewall blocks emulator external traffic; only a loopback-bound CI client via emulator port forwarding was used, not a LAN or user device.

No application released; do not enable network ADB or use this test on a real head unit.
